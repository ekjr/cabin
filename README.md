# Cabin

Magisk module for a rooted tablet. The phone pairs like a car stereo. Calls open in the tablet's Phone app. Texts open in Messages, and also in Cabin.

Turn Cabin on or off from the Cabin app. Off leaves calls and texts on the phone.

Requires Magisk 20.4 or newer. Flash the module zip, reboot, then pair the phone and allow calls, contacts, and messages.
